# Superstore-Analytics

### Power BI Project
This project analyzes Superstore data to evaluate sales performance, profitability, customer behavior, and regional trends. A Power BI report was developed, combining historical data analysis with forecasting to explore future trends and support business planning. The report helps stakeholders gain meaningful insights, anticipate future performance, and make data-driven decisions.

### Tools Covered : Advanced Excel, Power BI, Power Query, DAX

### Key Performance Indicators (KPIs):

• Total Sales

• Total Profit

• Total Quantity

• Total Regions

• Total Products

• Total Customers

• Segment-wise Sales

• Monthly Profit

• Year-over-Year (YoY) Analysis

• Sales and Profit by Category and Subcategory

• Sales by Payment Mode

• Sales by Ship Mode

• Sales by Region

• Monthly Sales by YoY

• Sales Forecasting

• Profit Forecasting

• Customer Forecasting
